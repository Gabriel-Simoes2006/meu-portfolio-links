# 🔗 Portfólio & Agregador de Links

Página web responsiva desenvolvida em HTML5 e CSS3 para centralizar links profissionais e apresentar projetos na área de Tecnologia da Informação, Banco de Dados e Análise de Dados.

## 🚀 Tecnologias Utilizadas
- **HTML5 Semântico**
- **CSS3** (Flexbox, Variáveis CSS e Design Responsivo)
- **Font Awesome** (Ícones)

## 🌐 Como visualizar
Você pode abrir o arquivo `index.html` diretamente no navegador ou acessar a versão publicada via **GitHub Pages** nas configurações deste repositório.
